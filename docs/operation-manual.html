自動車販売管理システム（AutoDealerSphere） 操作マニュアル

1. はじめに

本書は、自動車販売管理システム「AutoDealerSphere」の操作マニュアルです。インストール方法、初期設定、および各画面の操作方法について説明します。

AutoDealerSphere は、自動車販売店向けの顧客管理システムです。顧客情報・車両情報・部品情報・請求書の管理、データのバックアップ・レストアなどの機能を提供します。

1.1. システム構成

表 1.1-1 システム構成
コンポーネント 種別 役割
AutoDealerSphere.Server.exe Windowsサービス Webサーバー（http://localhost:5259）として常駐します。
AutoDealerSphere.exe デスクトップアプリ ランチャー。起動するとサーバーに接続して操作画面を表示します。

サーバーはWindowsサービスとして自動的に起動しているため、利用者はデスクトップのランチャーアイコンをダブルクリックするだけで操作画面を開くことができます。

1.2. 動作環境

  • OS: Windows（64ビット）
  • Microsoft Edge WebView2 ランタイム（インストーラーに同梱されています）
  • インストール先: C:\AutoDealerSphere\

2. インストール

本章では、システムのインストール手順とアップデート手順を説明します。

2.1. 初回インストール

  1. インストーラー「AutoDealerSphere_Setup.exe」を右クリックし、「管理者として実行」を選択します。
  2. 画面の指示に従ってインストールを進めます。
  3. インストールが完了すると、Windowsサービス「AutoDealerSphere」が登録され、デスクトップに「AutoDealerSphere」アイコンが作成されます。
図 1 インストーラー画面
インストーラーは必ず「管理者として実行」してください。管理者権限がない場合、Windowsサービスの登録に失敗します。

2.2. インストール後の動作確認

  1. Windowsの「ファイル名を指定して実行」（Windowsキー + R）で「services.msc」を入力し、サービス一覧を開きます。
  2. 「AutoDealerSphere」サービスの状態が「実行中」になっていることを確認します。
  3. デスクトップの「AutoDealerSphere」アイコンをダブルクリックし、操作画面が表示されることを確認します。
図 2 サービス一覧での確認

2.3. アップデート（再インストール）

新しいバージョンをインストールする場合は、既存のサービスを停止・削除してからインストーラーを実行します。

  1. コマンドプロンプトを「管理者として実行」で開きます。
  2. 以下のコマンドを順に実行し、サービスを停止・削除します。
  3. 「AutoDealerSphere_Setup.exe」を管理者として実行します。
サービスの停止・削除コマンド
sc stop AutoDealerSphere
sc delete AutoDealerSphere
アップデートを行ってもデータベースは保持されます。念のため、アップデート前にバックアップ（「データ管理」の章を参照）を取得することを推奨します。

4. ログイン・ログアウト

4.1. ログイン

システムを起動するとログイン画面が表示されます。

図 5 ログイン画面
  1. メールアドレスを入力します。
  2. パスワードを入力します。
  3. 「ログイン」ボタンをクリックします。
  4. ログインに成功すると、顧客管理画面が表示されます。
メールアドレスまたはパスワードが誤っている場合は、エラーメッセージが表示されます。入力内容を確認して再度お試しください。

4.2. パスワードを忘れた場合

ログイン画面の「パスワードを忘れた場合」リンクから、パスワードの再設定ができます。

図 6 パスワードを忘れた場合の画面
  1. ログイン画面の「パスワードを忘れた場合」をクリックします。
  2. 登録されているメールアドレスを入力し、「送信」ボタンをクリックします。
  3. 届いたメールに記載されたリンクを開きます。
  4. 新しいパスワードを設定し、ログイン画面から再度ログインします。
パスワードリセットメールを送信するには、発行者情報管理画面でメール送信（SMTP）設定が完了している必要があります。

4.3. ログアウト

画面左側のメニューの「ログアウト」をクリックすると、ログイン画面に戻ります。

顧客管理画面では、顧客情報の検索・登録・編集・削除を行います。

6.1. 顧客の検索

図 8 顧客一覧画面
表 6.1-4 検索条件

7.4. 車検証JSONの取り込み

車両編集画面では、車検証情報のJSONファイルを取り込んで車両情報を自動入力できます。

  1. 車両編集画面上部の「車検証json取り込み」欄でJSONファイルを選択します。
  2. 「JSONデータを取り込み」ボタンをクリックします。
  3. 取り込み結果のメッセージを確認し、反映された内容を確認して保存します。
車検証JSONの取り込みは、登録済みの車両の編集画面でのみ利用できます。

9.1. 請求書の検索

  1. 請求書詳細画面の「明細追加」ボタンをクリックします。
  2. 項目名、タイプ、修理方法、数量、単価、工賃を入力します。部品管理に登録した部品を選択して入力することもできます。
  3. 「保存」すると明細一覧に追加され、小計・合計が自動計算されます。
  4. 登録済みの明細は、明細一覧の項目名をクリックすると編集・削除できます。
図 18 明細編集ダイアログ

9.5. 法定費用の追加

  1. 請求書詳細画面の「法定費用」ボタンをクリックします。
  2. ダイアログで該当する法定費用（自賠責保険料、重量税、印紙代など）を選択します。

9.6. Excel出力

  1. 請求書詳細画面の「Excel出力」ボタンをクリックします。
  2. 請求書がExcelファイルとしてダウンロードされます。

出力されるExcelファイルには、発行者情報管理画面で登録した自社情報（社名、住所、インボイス番号、振込先口座など）が印字されます。

10. データ管理

データ管理では、外部データの取り込み（インポート）、バックアップ、レストア（復元）を行います。

10.1. データインポート

CSVまたはTXTファイルから、顧客情報と車両データを一括で取り込みます。

図 19 車両データインポート画面
  1. メニューの「データ管理」>「データインポート」を開きます。
  2. 「インポートファイルを選択してください」からCSVまたはTXTファイルを選択します。
  3. 既存の車両データをすべて削除してから取り込む場合は、「既存データを置き換える」にチェックを入れます。
  4. 「インポート開始」ボタンをクリックします。
  5. インポート結果（新規顧客件数、車両データ件数、エラー詳細）を確認します。
表 10.1-9 インポートファイルの主なカラム
カラム名 説明
fld_顧客ID 顧客を識別する一意のID
fld_氏名 顧客の氏名
fld_郵便番号 顧客の郵便番号
fld_所有者の住所 顧客の住所
その他 車両番号、車体番号、車検証情報などの車両情報カラム
「既存データを置き換える」にチェックを入れると、既存の車両データはすべて削除されます。実行前にバックアップを取得することを推奨します。
アップロードできるファイルサイズは最大10MBです。

10.2. バックアップ

データベースの全データ（ユーザー、顧客、車両、車両カテゴリ、部品、法定費用、請求書、請求明細、発行者情報）をCSV形式（ZIP圧縮）でバックアップします。

図 20 データバックアップ画面
  1. メニューの「データ管理」>「バックアップ」を開きます。
  2. 「バックアップ開始」ボタンをクリックします。
  3. バックアップファイル（例: bk20260707-1030.zip）がダウンロードされます。
  4. バックアップ結果（各データの件数）を確認します。
バックアップファイルは、システムのトラブルに備えて定期的に取得し、パソコン本体とは別の場所（外付けドライブなど）に保管することを推奨します。

10.3. レストア

バックアップファイル（ZIP形式またはJSON形式）からデータを復元します。

図 21 データレストア画面
  1. メニューの「データ管理」>「レストア」を開きます。
  2. 「バックアップファイルを選択してください」からバックアップファイル（.zip または .json）を選択します。
  3. 「既存のデータを削除してレストアすることを理解しました」にチェックを入れます。
  4. 「レストア開始」ボタンをクリックします。
  5. レストア結果（各データの件数）を確認します。
レストアを実行すると、現在のデータはすべて削除され、バックアップファイルのデータに置き換えられます。この操作は元に戻せません。実行前に現在のデータをバックアップすることを強く推奨します。
アップロードできるファイルサイズは最大50MBです。

12. 発行者情報管理

発行者情報管理画面では、請求書に印字される自社情報と、パスワードリセットメールなどの送信に使用するメール（SMTP）設定を管理します。

図 24 発行者情報管理画面

12.1. 発行者情報の入力項目

表 12.1-11 発行者情報の入力項目
分類 項目 説明
会社情報 郵便番号 自社の郵便番号
住所 自社の住所
社名 請求書に印字される社名
役職・氏名 代表者などの役職と氏名
電話番号・FAX番号 自社の連絡先
インボイス番号 適格請求書発行事業者の登録番号
振込先口座 銀行名・支店名 振込先の銀行名と支店名（複数口座の登録が可能）
口座種別・口座番号・名義人 振込先口座の詳細
  1. 各項目を入力します。
  2. 「保存」ボタンをクリックします。

12.2. メール送信（SMTP）設定

パスワードリセットメールを送信するためのメールサーバー設定です。ご利用のメールサービスの情報を入力してください。

表 12.2-12 メール設定の入力項目
項目 説明 入力例
SMTPホスト メール送信サーバーのホスト名 smtp.gmail.com
SMTPポート メール送信サーバーのポート番号 587
SSL/TLS使用 暗号化通信を使用するかどうか 使用する
送信者メールアドレス メールの差出人アドレス noreply@example.com
送信者名 メールの差出人名 AutoDealerSphere
SMTP認証ユーザー名 メールサーバーの認証ユーザー名 -
SMTP認証パスワード メールサーバーの認証パスワード -
  1. 各項目を入力します。
  2. 「接続テスト」ボタンをクリックし、設定が正しいことを確認します。
  3. 「保存」ボタンをクリックします。
接続テストを実行するには、SMTP認証パスワードの入力が必要です。パスワードが未入力の場合、メール設定は保存されません。
